Bookmarks.

The links, files and folders for each piece of work sit right in its group’s tile. Switch groups, and the right ones come along.

Get DesktopHQ

Every group, its own links.

Every state lives in the same spot in your bar, so nothing around it ever moves.

A link

A round chip with the site’s first letter, one colour per site.

A file or folder

Its Finder icon, faded if it has gone missing.

Hover

The name and the site, and the Chrome profile it opens in.

Per group

Links, files and folders are saved with the group, in the order you added them.

Opens in place

A click switches to the tab if it’s open, else opens it in the group’s own Chrome window and profile.

Hyper+D

Saves the tab you’re on to the group you’re in, with Edit and Undo on the card.

Files and folders too

Add a folder that opens in Cursor, or any file with its default app.

Edit or move

Right-click to rename, change the profile, move to another group, or remove.

Plays well with DesktopHQ

Stored as group resources in the same workspaces.json format.

Shortcuts.

  • Bookmark this tab: Hyper + D

Hyper is ⌃⌥⇧⌘ held together, or one key mapped to it.

Adding it.

  1. Click Add Bookmarks. The link opens DesktopHQ. Nothing is downloaded.
  2. Confirm. DesktopHQ asks “Add Bookmarks to your bar?” before anything changes.
  3. Find it in your bar. It flashes once so you can spot it. Turn it off any time in Settings → Plugins.
