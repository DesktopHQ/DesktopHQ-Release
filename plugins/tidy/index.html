Plugin · built into DesktopHQ2

Tidy.

Tidy straightens the group you’re in: stray windows come back on screen, and every edge and seam gets the same 16-point gap.

Get DesktopHQ

One click. Every gap even.

Every state lives in the same spot in your bar, so nothing around it ever moves.

Ready

Two tiles in a ring. Click it, or press Hyper+T.

Tidied

A green check for 1.5 seconds while the windows glide into place.

One pass, on request

The bar button, the menu or Hyper+T. It never moves anything by itself and holds no state.

Edges

Windows past an edge are pulled back; ones within 48 points of it settle exactly 16 points in, above the floating bar.

Seams

Neighbours side by side or stacked meet 16 points apart, halfway or against a window already placed.

Keeps sizes sane

No window ends smaller than 300 × 250. Heavily overlapping windows are left alone.

Every display

Each window is tidied on the display its centre is on.

Guests included

Windows visiting the group are tidied with it; other groups are never touched.

Shortcuts.

  • Tidy up this group: Hyper + T

Hyper is ⌃⌥⇧⌘ held together, or one key mapped to it.

Adding it.

  1. Click Add Tidy. The link opens DesktopHQ. Nothing is downloaded.
  2. Confirm. DesktopHQ asks “Add Tidy to your bar?” before anything changes.
  3. Find it in your bar. It flashes once so you can spot it. Turn it off any time in Settings → Plugins.
